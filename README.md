# Nutrition LLM benchmark

This repository contains the code and derived data for our comparison of three
LLM-based systems on questions from ESPEN nutrition guidelines. The final data set
has 60 questions and 180 rated answers: 60 each from Open Evidence, GPT-5.5 and
Sonar Reasoning Pro.

The questions come in 30 topic pairs. Each topic has one knowledge question and
one case question based on the same recommendation. Analyses of guideline
reference therefore use the topic as the independent unit where systems are
compared.

## Folders

- `analysis/` contains the manuscript analysis supplied by Gero Lueg.
- `verification/` contains an independent reconstruction of the central results.
- `querying/` contains the prompt, question workbooks and API collection code.
- `data/` contains the derived analysis tables. It does not contain answer texts.
- `figures/` contains the figure generated by the analysis code.
- `docs/` contains the statistical notes and citation-analysis documentation.
- `archive/` keeps the earlier citation extraction for traceability.

The private rating workbooks, answer texts and unblinding key are not included.

## Reproduce the analysis

Python 3.10 or newer is required.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
sh run_all.sh
```

The scripts use fixed random seeds. `run_all.sh` reproduces the deposited-data
analysis and then runs the independent checks.

To run only the independent reconstruction:

```bash
.venv/bin/python verification/verify_key_results.py
.venv/bin/python -m unittest discover -s verification -p 'test_*.py'
```

`verification/verify_raw_workbooks.py` can additionally reconcile an authorized
local copy of the private key, consensus workbook and both rater workbooks. It
requires their paths explicitly and does not copy their contents into the repository.

The five central numbers requested for independent checking were confirmed. The
exact permutation calculations are very close to the manuscript's seeded Monte
Carlo estimates. Two additional sensitivity checks matter: the marginal domain
comparison and the nominal accuracy omnibus result are weaker when the 30 paired
topics, rather than the 60 questions, are used as the independent units. The
Sonar sample also includes 13 replacement calls made with a larger token limit
after the initial exports contained sources but no answer. Details are in
[`docs/independent_verification.md`](docs/independent_verification.md).

## Query collection

The API code is described in [`querying/README.md`](querying/README.md). API keys
are read from the environment or a local `.env` file and must not be committed.
Open Evidence answers were exported manually; no Open Evidence API was used.
